## 🚀 3-Step Quick Start

### Step 1: Install (on your machine)
```bash
cd D:\Calude_root\Portfolio\portfolio
npm install
```

### Step 2: Run Locally
```bash
npm run dev
# Opens at http://localhost:3000
```

### Step 3: Deploy
```bash
npm run build
# Deploy dist/ folder to Vercel/Netlify
```
